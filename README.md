# Cats and Dogs

A static website about cats and dogs, including the history of the French Bulldog and of Siamese cats, and a light-hearted look at cats vs dogs.

Built by the Orchestrate Solutions demo team. Plain HTML, CSS and JavaScript, with no build step.

## Pages
- `index.html`: home
- `pages/french-bulldog.html`: history of the French Bulldog
- `pages/siamese.html`: history of the Siamese cat
- `pages/cats-vs-dogs.html`: cats vs dogs

## Structure
- `css/tokens.css` design tokens, `css/layout.css` layout and navigation, `css/site.css` base styles
- `js/nav.js` navigation, `js/app.js` page behaviour
- `assets/` original SVG illustrations and icons

Open `index.html` in a browser to view it.
